# 한국어 제출 문서 (표, 아키텍처, 서비스 흐름)

## Overview

공모전 기획안, 제안서, 사업계획서 같은 한국어 제출 문서를 Word로 만들 때 지키는 규칙 모음이다. 실제 제출 문서를 고치면서 받은 지적을 모았다. 처음부터 이대로 만들면 같은 지적을 다시 받지 않는다.

**도형과 글자만으로 그린 그림, 이모지, 사진은 쓰지 않는다. 그림의 구성 요소는 무료 컬러 아이콘이다.** 가장 자주 어기는 규칙이다.

## 문서 전체

| 항목 | 규칙 |
|---|---|
| 형식 | Word(.docx)가 원본이다. PDF는 Word에서 내보낸다 (`scripts/word_to_pdf.py`). HTML로 만들어 PDF로 찍지 않는다. |
| 말투 | 모든 문장은 '~음, ~함, ~임'으로 끝낸다. 따옴표로 따온 화면 문구와 사람 말은 그대로 둔다. |
| 문장부호 | 엠대시(—)와 가운데점(·)을 쓰지 않는다. 나열은 쉼표, '와/과', '및'으로 쓴다. 제목도 마찬가지다 ("AI 및 데이터 활용 계획"). |
| 번호 | 번호 상자, 원문자(①②)를 쓰지 않는다. 장과 절 번호(1., 2.1)만 글자로 쓴다. |
| 글꼴 | Pretendard. 본문 약 10pt, 표 약 9pt. 너무 작게 줄이지 않는다. |
| 글씨 색과 크기 | 글씨는 **검정 한 가지**. 크기는 **본문 크기와 표 크기 두 가지만** 쓴다. 회색 글씨, 본문보다 작은 보조 문단, 표 안의 작은 회색 부제, 초록, 파랑, 주황 같은 색 강조를 쓰지 않는다. 강조는 굵게만 한다. 캡션, 목록, 메모 칸도 본문 크기다. 예외는 제목 번호, 표 머리글 강조 열, 머리글과 바닥글, 참고 자료 목록. |
| 쉬운 말 | '뉴로 심볼릭', '반사실 설명' 같은 전문 용어를 제목이나 캡션에 쓰지 않는다. 하는 일을 쉬운 말로 쓴다 (예: 'AI는 글을 다루고, 숫자는 규칙으로 계산'). |
| 문장 문단 | 첫 줄을 한 글자(3.5mm) 들여쓴다. |
| 목록 | Word 글머리표(파란 점, 내어쓰기)로 만든다. 항목은 굵은 첫 문장으로 시작한다. |
| 강조 상자 | 왼쪽에 색 선이 있는 상자는 쓰지 않는다. 들여쓴 문장 문단으로 쓴다. |
| 요약 카드 | 본문 내용을 숫자 카드로 되풀이하는 상자(예: "지금 14개 / +11개 / +10개" 카드 3개)는 넣지 않는다. 같은 내용을 두 번 보여 줄 뿐 정보가 늘지 않는다. |
| 캡션 | 모든 그림과 표에 **Word 캡션 기능**(캡션 스타일 + SEQ 필드)으로 제목을 단다. 그림은 그림 **아래 가운데**에 `(그림 1) 제목`, 표는 표 **왼쪽 위**에 `<표 1> 제목`. 번호는 그림과 표를 따로 센다. 그림 설명이 길면 캡션은 제목만 두고 설명은 캡션 아래 들여쓴 본문으로 쓴다. `docx_helpers.caption()`을 쓴다. |
| 쪽수 | 제한 쪽수가 있으면 내보낼 때마다 `scripts/pdf_check.py`로 쪽수와 쪽별 남은 여백을 잰다. |

## 표

- 모든 칸의 글자는 **세로 가운데**로 맞춘다.
- 왼쪽 항목 칸, 날짜 칸, '모의/실'이나 '구현' 같은 짧은 칸은 **가로도 가운데**로 맞춘다.
- 여러 줄짜리 설명 칸은 왼쪽 정렬로 둔다.
- 머리글 행은 연회색 바탕에 굵은 글씨로 하고, 강조할 열만 파란 바탕에 흰 글씨로 한다.
- **표 위 선, 머리글 아래 선, 표 맨 아래 선은 같은 굵은 검정 선(1.25pt)**으로 한다. 칸 사이 선만 연회색 가는 선(0.5pt)이다. 머리글이 없는 표도 위와 아래는 굵은 검정이다. 머리글 아래 선은 머리글 칸의 아래 테두리와 첫 데이터 행 칸의 위 테두리에 함께 넣는다 (`examples/example_build_docx.py`의 `dtable`).
- 머리글 행 반복을 켜고, 행이 쪽 사이에서 잘리지 않게 한다.
- 단계나 구조를 보여 주는 표(서비스 흐름, 구조도)는 표로 두지 말고 그림으로 바꾼다.

## 그림: 아키텍처와 서비스 흐름

**구성 요소는 반드시 무료 컬러 아이콘 이미지로 그린다.** 기본은 Icons8 Flat Color Icons(MIT, 출처 표기 불필요, 329개)이다.

| 피할 것 | 이유 |
|---|---|
| 네모 상자에 글자만 넣은 도형 그림 | 글자를 상자에 옮겨 담았을 뿐이라 그림으로서 전하는 것이 없다. |
| 이모지(Fluent Emoji 등) | 글자처럼 보여 문서가 가벼워 보인다. |
| 실제 사진(스톡 사진) | 구성 요소를 나타내지 못하고 장식이 된다. |

"실제 이미지 같은 아이콘"을 원하면 사진이 아니라 아이콘 사이트(Icons8, Flaticon)의 그림 아이콘을 뜻하는 경우가 많다. 무엇을 원하는지 애매하면 아이콘 후보 시트(`fetch_icons8.py`가 만드는 `_sheet.png`)를 먼저 보여 준다.

**아키텍처 그림:**
- 계층 칸을 둔다. 예: 이용자 / 화면 / 서버 / AI 플랫폼, 아래쪽에 데이터와 일괄 처리.
- 구성 요소마다 동그라미 안에 아이콘을 넣고, 옆에 이름과 설명 한두 줄을 쓴다.
- 동그라미 테두리로 종류를 나누고 범례를 단다. 생성형 AI는 파란 테두리, 규칙 엔진은 굵은 검정, 데이터는 회색이다.
- 화살표 위에는 오가는 내용을 짧은 라벨로 단다.

**서비스 흐름 그림:**
- 사람(예시 인물)이 단계를 지나가는 여정으로 그린다.
- 단계마다 아이콘, 단계 이름, 이용자가 하는 일, AI나 규칙 엔진이 하는 일(표시 칩), 걸리는 시간(시계 아이콘)을 넣는다.
- 결과 예시는 말풍선 하나로 보여 준다.

**공통:**
- 글자는 25px(약 7pt) 이상으로 한다.
- 그림은 SVG로 Word에 넣는다. PDF에서도 벡터로 남는다.

## 만드는 순서

1. 아이콘 고르기: `python scripts/fetch_icons8.py --list`로 이름을 확인하고, `python scripts/fetch_icons8.py <폴더> name...`으로 받는다. `_sheet.png`를 열어 보고 고른다.
2. 그림 그리기: `scripts/svgdiagram.py`의 `Canvas`, `tier`, `node`, `arrow`를 쓴다. 완성 예시는 `examples/example_diagrams.py`에 있다.
3. PNG로 확인하기: `python scripts/svg_to_png.py fig.svg`로 만든 PNG를 Read로 직접 보고 겹침과 잘림을 고친다.
4. 문서 만들기: `scripts/docx_helpers.py`를 쓴다. 표는 `table`, `cell(valign='center')`, `fill`, 그림은 `picture_svg`, 캡션은 `caption(doc, '그림' 또는 '표', 제목)`, 목록은 numPr 글머리표다. 완성 예시는 `examples/example_build_docx.py`에 있다.
5. PDF 내보내기: `python scripts/word_to_pdf.py doc.docx --embed-fonts --pages 10` (Windows와 Microsoft Word 필요)
6. 점검하기: `python scripts/pdf_check.py doc.pdf`로 쪽수, 남은 여백, 글꼴을 확인한다.

## Common Mistakes

| 증상 | 원인과 해결 |
|---|---|
| PDF에 글자가 그림으로 들어감 (글자 쪽에 래스터 이미지 수백 개) | Pretendard가 OTF로 설치돼 있음. TTF판(`pretendard/dist/public/static/alternative/*.ttf`)으로 다시 설치한다. |
| 글꼴이 Calibri로 바뀜 | Bold 등 필요한 굵기가 설치돼 있지 않음. 설치된 굵기를 확인한다. |
| Cambria Math가 섞임 | en space(U+2002) 같은 특수 공백을 썼음. 일반 공백으로 바꾼다. |
| 그림이 PNG로 안 바뀜 (Tainted canvas) | SVG에 foreignObject가 있음. mermaid라면 htmlLabels를 끈다. 이 스킬의 svgdiagram은 쓰지 않는다. |
| 목록의 왼쪽 선이 끊겨 보임 | 문단 테두리로 그렸음. 글머리표 목록으로 바꾼다. |
| 작은 글씨를 본문 크기로 키웠더니 쪽이 넘침 | 글자를 줄이지 말고 내용을 줄인다. 다른 표와 겹치는 줄, 같은 말을 되풀이하는 문장부터 뺀다. |
| 내용을 조금 더했더니 쪽이 넘침 | `pdf_check.py`로 쪽별 여백을 보고, 넣기 전에 같은 쪽에서 줄일 곳을 정한다. |
| 캡션 번호가 틀리거나 비어 있음 | SEQ 필드가 갱신되지 않았음. `word_to_pdf.py`가 내보내기 전에 필드를 갱신한다. Word에서는 Ctrl+A, F9. |
| 캡션을 더했더니 쪽이 넘침 | 캡션 한 줄은 약 5mm다. 표가 많은 쪽은 미리 줄일 곳을 정한다. |
| mermaid로 그리면 선이 엉키고 글자가 4~5pt로 작아짐 | 이런 문서 그림은 svgdiagram으로 직접 배치한다. |
